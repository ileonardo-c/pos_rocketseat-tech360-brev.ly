# Web

SPA React + Vite para gerenciamento de links encurtados.

## Requisitos

- Node.js 22+
- pnpm 11+

## Configuração

1. Copie `.env.example` para `.env`.
2. Ajuste `VITE_API_BASE_URL` para a URL da API.

## Rodar local

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Testes

```bash
pnpm test
```
